# 사용자 사전 준비사항

이 문서는 회의 녹취록 생성기를 사용하기 전에 준비해야 할 것들을 안내합니다.

---

## 1. Google 계정

- Gmail 등 Google 계정이 필요합니다
- Google Drive와 Google Colab에 접속할 수 있어야 합니다

## 2. Google Drive 여유 공간

- **최소 15GB 여유 공간** 필요
  - 모델 캐시: ~14GB (최초 1회 다운로드)
  - 오디오 파일 + 결과 파일: ~1GB
- 최초 실행 후에는 모델이 캐시되어 추가 다운로드가 없습니다

## 3. Google Drive 폴더 생성

내 드라이브에 다음 폴더를 만드세요 (노트북이 자동 생성하지만, 미리 만들어도 됩니다):

```
내 드라이브/
  회의녹음/
    input/     ← 여기에 m4a 파일을 넣으세요
    output/    ← 여기에 결과가 저장됩니다
```

## 4. Google Drive 데스크탑 앱 (권장)

PC에서 Drive 폴더에 바로 파일을 넣고 결과를 확인하려면 데스크탑 앱 설치를 권장합니다:

1. https://www.google.com/drive/download/ 에서 다운로드
2. 설치 후 Google 계정 로그인
3. 탐색기에서 `Google Drive > 내 드라이브 > 회의녹음` 폴더에 바로 접근 가능

## 5. Colab 런타임 설정 (중요)

Colab에서 GPU를 사용해야 합니다. 최초 1회 설정:

1. Colab 노트북을 엽니다
2. 상단 메뉴 > **런타임** > **런타임 유형 변경**
3. **하드웨어 가속기**를 **T4 GPU**로 선택
4. **저장** 클릭

## 6. 오디오 파일 준비

- **지원 형식**: `.m4a` (핸드폰 녹음, 노트북 녹음 기본 형식)
- **최대 길이**: 60분 이내 권장
- **파일명**: 한글, 영어, 숫자 모두 가능 (예: `주간회의_20260331.m4a`)

### 녹음 팁
- 가능하면 조용한 환경에서 녹음
- 마이크와 화자 간 거리가 가까울수록 인식률이 높음
- 핸드폰 녹음 시 회의 테이블 중앙에 놓는 것을 권장

## 7. 예상 소요 시간

| 항목 | 시간 |
|---|---|
| 최초 환경 설치 | ~3-5분 |
| 최초 모델 다운로드 | ~5-10분 (1회만) |
| 이후 모델 로드 | ~1-2분 |
| 10분 오디오 처리 | ~2-3분 |
| 30분 오디오 처리 | ~5-8분 |
| 60분 오디오 처리 | ~10-15분 |

## 8. 주의사항

- Colab 무료 버전은 **연속 사용 시간이 제한**됩니다 (약 90분 미사용 시 세션 종료)
- 처리 중에는 브라우저 탭을 닫지 마세요
- 주 4-5건 처리 시 한 세션에서 모두 처리 가능합니다 (30분 회의 기준 ~40분 소요)
